# 🕵️‍♂️ AI Mystery Detective

An interactive, multi-level retro noir mystery investigation web game powered by **Python Flask**, **Gemini API**, **SQLite**, and **Web Audio API**.

---

## 🎮 Key Features
- **🧠 Dynamic AI Interrogation:** Real-time suspect interrogation driven by Google Gemini API with custom suspect personas and hidden alibis.
- **📈 Polygraph & Stress Engine:** Interactive real-time ECG oscilloscope wave that tracks suspect heart rate and stress spikes during tough questioning.
- **🔦 Interactive UV Flashlight Mode:** Darkened crime scenes searchable via UV spotlight to illuminate hidden physical evidence.
- **💾 SQLite Progress Persistence:** Tracks player score, cases solved, and collected clues in real time.
- **🎵 Retro Synth SFX Engine:** Procedural sound effects using Web Audio API (typewriter clatter, tension alerts, victory fanfares) without heavy audio files.
- **💥 Retro Arcade Aesthetics:** CRT scanline shaders, suspect trembling animations, and screen-shake impact effects.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLite3, Google GenAI SDK
- **Frontend:** HTML5, CSS3 (CRT Shader & CSS Keyframe Animations), Vanilla JavaScript (Web Audio API, HTML5 Canvas)
- **Environment:** Dotenv
